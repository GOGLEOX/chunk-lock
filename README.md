# Chunk Lock

Simple chunk claiming for Minecraft.

Chunk Lock was made for servers that just want land protection without dragging in factions, economies, taxes, ranks, menus, or a hundred commands.

Claim land.
Trust friends.
Protect builds.
Keep playing.

---

## Features

- Chunk claiming
- Player trust system
- Wilderness support
- Claim HUD
- Connected claim outlines
- Optional explosion protection
- JourneyMap support
- Admin inspect tools

---

## Built For

- Survival servers
- Small SMPs
- Lightweight modpacks
- Utility-focused servers

---

## Compatibility

- Minecraft `1.20.1`
- Forge `47.4.20+`
- Java `17`
